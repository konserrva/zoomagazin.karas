План API: товары зоомагазина 

Сущность: Product (товар)
 Поле      Тип      Кто задаёт   Правило проверки                     

 Id        int      сервер        -                                    
 Name      string   пользователь  обязательно, 2–100 символов          
 Category  string   пользователь  обязательно                          
 Price     decimal  пользователь  от 1 до 1 000 000                    
 Stock     int      пользователь  от 0 до 100 000                      

 Метод   Адрес               Действие         Коды ответа   

 GET     /api/products       Список товаров   200           
 GET     /api/products/{id}  Один товар       200, 404      
 POST    /api/products       Добавить товар   201, 400, 409 
 DELETE  /api/products/{id}  Удалить товар    204, 404      

Бизнес-правило: название товара должно быть уникальным  409 Conflict.
